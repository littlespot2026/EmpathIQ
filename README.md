# EmpathIQ - 同理心与社交读心 MVP 应用

> **“看穿言外之意，接住真实情绪”**  
> 一款基于认知心理学、非暴力沟通（NVC）与大语言模型架构的跨平台社交潜台词透视与情境对练应用。

---

## 🌟 核心功能清单与页面实现

### 1. 首页 / 仪表盘 (Home Dashboard)
- **顶部状态栏**：品牌 Logo、极简标语及动态胶囊标签 `今日剩余透视: 3/3`（本地自动每日刷新）。
- **潜台词解码器卡片**：
  - 300 字限制多行输入框，带实时字数计数器。
  - **自动剪贴板检测**：聚焦与返回前台时自动探测剪贴板内容，浮现一键粘贴胶囊。
  - **关系维度 Chips**：`伴侣`（默认）、`职场/主管`、`朋友`、`长辈/父母`。
  - **一键透视潜台词**：输入有内容时高亮，点击带有 Loading 动效与每日配额校验。
- **次级卡片（今日社交残局）**：
  - 展示当日人际残局，包含全网通关率标签（如 `通关率 34%`），一键进入挑战。
- **底部历史列表**：
  - 本地缓存最近 10 条解码记录，展示时间、情绪温度标签，点击可无损重温历史分析。

### 2. 解码分析结果页 (Decoder Results)
- **情绪冰山卡片**：
  - **动态情绪温度计**：冷淡蓝 (0~30°C) -> 焦躁黄 (31~70°C) -> 易燃红 (71~100°C)。
  - **心理心防/戒备度仪表**：0%~100% 动态量化。
  - **水面之下心理动机**：表面陈述 vs 真实潜台词 vs 核心痛点。
- **实战破局三策**：
  - **策略 A：稳妥共情牌**（一键复制 + 触觉震动 + 动态勾选动效）。
  - **策略 B：幽默破冰牌**。
  - **策略 C：温和界限牌**（强调健康边界，拒绝无底线讨好）。
  - 每项策略配有可折叠/展开的 `为什么有效（心理机制与底层逻辑）`。
- **底部操作栏**：
  - `保存分享卡片`：跳转至 Canvas 渲染器生成 9:16 长图。
  - `带入情境对练`：携带当前上下文直接启动 1分钟对练沙盒。

### 3. 1分钟对练沙盒 (Conflict Sandbox)
- **顶部固定 HUD**：
  - 角色当前的 `怒气/防御值`（随对话得分增减）。
  - 角色**实时内心潜台词活动**（如 “他好像真的听懂了我的委屈...”）。
- **即时对练气泡界面**：
  - AI 根据玩家回复给出即时反馈标签（如 `【怒气 -20%】精准识别情绪，心防瓦解` 或 `【怒气 +15%】触发自恋防御`）。
- **轻量级共情提示胶囊 (Coaching Hint)**：
  - 提供即时倾听与复述技巧指导，附带一键使用破局话术 Chips。
- **复盘结算弹窗**：
  - 3~5 轮后自动结算，给出 100 分制复盘得分、段位评级（如 `Lv.4 情绪拆弹专家`）、四维共情雷达维度及导师点评。

### 4. 本地分享长图生成模块 (Share Poster)
- 基于 Flutter `RepaintBoundary` 原生 Canvas 渲染 9:16 黄金比例海报。
- 包含：品牌标识、段位徽章（`Lv.4 洞悉者`）、原句与关系标签、情绪温度与防御指数、破局金句精选与心理机制、矢量二维码与 Slogan。
- 支持一键导出保存至本地或相册。

### 5. 今日社交残局挑战 (Dilemma Challenge)
- 精选伴侣冷战、职场隐性否定、代际沟通等高难度社交场景。
- 单选推演，即刻揭晓避坑机制与高段位破局逻辑。

### 6. AI 引擎与设置配置 (Settings)
- 支持无缝切换 **Google Gemini API** (`gemini-3.5-flash`, `gemini-3.5-flash-lite` 等，经由 Vercel 安全 Serverless 代理接入) 与 **OpenAI 兼容接口** (`gpt-4o-mini`, DeepSeek, 通义千问等)。
- 密钥由 Vercel 环境变量安全管理，或由用户在本地设备 `SharedPreferences` 保存，严禁前端硬编码。
- **免 Key 智能心理学模拟模式**：未填 Key 或离线状态下自动启用预设心理学推演引擎，开箱即用。
- 提供“重置今日 3 次额度”便捷调试按钮。

## 🛠 技术架构与设计规范

- **代码架构**：单代码库多端输出（Web / Android / iOS / Desktop）。
- **视觉风格**：现代低饱和度深色/暖米色排版（Slate Charcoal `#0F1115` + Warm Beige `#EAD8C0` + Amber Sand `#D4A373`）。
- **多端适配**：在桌面端/Web 端自动采用精致的手机比例预览容器（Max Width 480px），在移动端自适应全屏沉浸式布局。
- **数据持久化**：采用 `shared_preferences` 实现 10 条历史、每日打卡和每日 3 次额度限制。

## 🚀 启动与运行指南

### 1. 启动 Web 端运行 (推荐)
```bash
flutter run -d chrome
```

### 2. 编译生产 Web 静态包
```bash
flutter build web
```
产物位于 `build/web` 目录下，可直接部署至任何静态托管服务（如 Netlify、Vercel 或 GitHub Pages）。

### 3. 运行于 Windows 桌面端
```bash
flutter run -d windows
```

### 4. 运行于 Android / iOS 真机或模拟器
```bash
flutter run
```
